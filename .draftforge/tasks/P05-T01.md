# P05-T01 — Waiting project lock, recovery state contracts, and repaid Phase 4 debts

Status: ready

## Objective

Lay the state foundation Phase 5 builds on: make the project lock wait instead
of refusing contention and delete the in-process `DispatchGate` workaround,
extend the task transition graph and canonical state with durable recovery
records, advance the state and execution schemas with a migration, and let the
worker execution seam accept a `running` attempt manifest so resume no longer
rewinds one.

## Acceptance criteria

- `withProjectLock` waits for a held lock with a bounded retry and a clear
  timeout error instead of failing immediately on contention. Stale-lock
  recovery behavior is preserved unchanged, and a test proves two concurrent
  callers serialize rather than one refusing.
- `DispatchGate` is deleted from `src/application/execution.ts` and no caller
  releases and re-acquires a lock around a model call. Concurrent dispatch
  behavior proven in P04-T04 still holds.
- The transition graph adds exactly one automation edge, `review -> active`, and
  an explicitly actor-recorded `blocked -> ready` reopen. No other edge changes.
  Illegal transitions still throw, and `ready` still requires done dependencies.
- Canonical state advances to schema version 3. `TaskState` gains a nullable
  review record carrying the repair counter, the last failure classification
  from the ADR 0010 taxonomy, and the last review attempt reference.
  `migrateProjectState` upgrades both version 1 and version 2 documents, and a
  version 3 document round-trips unchanged.
- The execution attempt manifest gains the `verifying`, `reviewing`,
  `repairing`, and `integrated` lifecycles plus nullable verification, scan,
  verdict, usage, and integration sections. Unknown properties are still
  rejected and existing Phase 4 manifests still validate.
- `.draftforge/schema/*.json` and `templates/schema/*.json` stay byte-identical
  and `test/templates.test.ts` passes.
- `executeClaimedWorker` accepts a `running` manifest with a non-null base
  commit directly. `resume` no longer rewinds an interrupted manifest to
  `claimed` with `baseCommit: null`, and reconciliation remains idempotent
  across every crash boundary P04-T04 covers.
- `npm run check` passes.
