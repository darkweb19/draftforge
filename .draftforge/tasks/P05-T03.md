# P05-T03 — Reviewer prompt, verdict envelope, and failure classification

Status: backlog

## Objective

Add the judgment half of review: a bounded reviewer prompt carrying only the
task contract, the authoritative diff, and machine evidence; a strict
single-envelope verdict contract parsed in the application layer; and the closed

## Acceptance criteria

- The reviewer prompt includes the task contract, the objective, owned paths,
  the authoritative changed-path list, the diff, and the machine evidence
  summary. It excludes unrelated task contracts, canonical state, and any
  environment or secret value. Prompt text is asserted in tests.
- The prompt states that a failed machine check cannot be accepted, and asks for
  exactly one JSON envelope. A response containing zero or more than one
  envelope is a `contract-violation`.
- The verdict envelope is validated strictly in `src/domain/reviewer.ts`:
  unknown properties rejected, verdict one of `accept`, `reject`, or `block`,
  each finding carrying a non-empty summary and a repository-relative path
  normalized with the existing worker-path rules.
- A `reject` verdict must carry at least one finding; `accept` must carry none.
  A verdict is classified `review-rejection` for `reject` and
  `contract-violation` for a malformed envelope.
- The reviewer decision function takes machine evidence and the model verdict and
  returns the effective outcome: acceptance requires both a passing machine
  result and an `accept` verdict; a failed machine result yields its own
  classification regardless of the verdict; a `reject` or `block` over passing
  machine evidence still rejects. Every combination is covered by a test table.
- The reviewer call is a text-only role call routed through the existing runner
  and works on both harness and API adapters. Transparent retry is permitted
  because a reviewer call has no workspace side effects.
- Classification values come from the ADR 0010 taxonomy and nothing else; an
  unrecognized cause maps to `unknown` rather than being invented.
- `npm run check` passes.
